
# The Agent Landscape

Different types of offerings related to AI Agents.

| Category | What it is | Who is it for? | Examples |
|---|---|---|---|
| **Builders** | Herramientas visuales o low-code/no-code para construir agentes sin tener que programarlo todo desde cero. | Principalmente usuarios no técnicos o con poca programación. | n8n, ElevenLabs, OpenAI Agent Builder, CrewAI Studio |
| **Products** | Productos ya construidos que incorporan agentes y que el usuario puede utilizar directamente. | Usuarios no técnicos que quieren **usar** agentes, no necesariamente desarrollarlos. | Claude Code, Cowork, OpenClaw, Claude Design |
| **Runtimes** | Entornos o plataformas donde un agente puede ejecutarse. Proporcionan infraestructura, ejecución, escalabilidad, acceso a servicios, etc. | Usuarios técnicos que quieren **ejecutar** agentes. | AWS Lambda, AWS Bedrock AgentCore, Claude Managed Agents, Vertex AI Agent Engine |
| **Frameworks** | Librerías y frameworks de programación para desarrollar agentes desde código. | Desarrolladores y usuarios técnicos que quieren construir agentes de forma personalizada. | OpenAI Agents SDK, CrewAI, LangGraph / LangChain, Google ADK |

---

# 1. Builders

Los **Builders** son herramientas que facilitan la creación de agentes, normalmente mediante una interfaz visual.

La idea es:

```text
No-code / Low-code
        ↓
Arrastrar componentes
        ↓
Configurar LLM
        ↓
Configurar Tools
        ↓
Crear Agent
````
